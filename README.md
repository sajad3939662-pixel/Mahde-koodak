# سامانه مدیریت مهدکودک (KinderGuard)

سامانه مدیریت مهدکودک (KinderGuard) پلتفرمی مدرن برای ارتباط امن والدین با مربیان است. قابلیت‌های کلیدی: ثبت پروفایل و آلرژی کودکان، گزارش‌های لحظه‌ای روزانه (غذا، خواب، فعالیت)، حضور و غیاب هوشمند و اعلان‌های اضطراری. هدف این پروژه حذف روش‌های سنتی و افزایش آرامش خاطر والدین در طول روز است.
